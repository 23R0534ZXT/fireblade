# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, criticise code and ideas rather than people, and do not
harass anyone.

To report a conduct problem, use the private report described in [SECURITY.md](SECURITY.md) and
say that it is a conduct report; the maintainer will answer privately.
