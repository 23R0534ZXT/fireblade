# Archives du prototype

Ces documents, mesures et captures sont conservés comme historique. Ils décrivent des versions antérieures, parfois sous le nom de travail Timeline Next et avec l’ancienne arborescence.

Les commandes, noms de fichiers et descriptions de distribution de ces archives ne constituent pas les instructions actuelles. Voir le README à la racine, docs/guides/UTILISATION.md et docs/development/ARCHITECTURE.md.

- `measurements/` : résultats bruts historiques ; les mesures Linux ne sont pas une validation Windows.
- `screenshots/` : anciennes captures.
- `VALIDATION.md`, `PROTOTYPE.md` : périmètres et limites des essais antérieurs.
- `DEMARRAGE-WINDOWS-ANCIEN.txt` : ancien mode de distribution en dossier.

Les outils actuels de reproduction sont dans scripts/benchmarks/. Aucun gain face à Timeline Explorer n’est établi par ces archives.
