# Public presentation of the repository

The owner of the account sets these fields in the **About** section (the gear on the
GitHub repository page). The account used for maintenance does not hold the
administration rights needed to change them: GitHub answers HTTP 403.

## About

**Description**

> Local DFIR workspace for parsing forensic artifacts, investigating timelines, hunting
> IOCs, and preserving case evidence — desktop (Windows) and host (beta, Docker) from
> one engine.

**Topics**

`dfir` · `digital-forensics` · `incident-response` · `forensics` · `timeline` ·
`windows-forensics` · `evtx` · `prefetch` · `hayabusa` · `python` · `pyside6` ·
`duckdb` · `docker`

## What the page shows first

- The README's two-edition table, and the beta warning under it.
- The Windows validation badge on `main`.
- The latest release with its zip and its SHA-256.

## What not to promise on the page

No support, no SLA, no "production ready". The Host has no access control and the Desktop is
unsigned; saying so is what keeps the page honest.
