# Fireblade 0.2.2 — modular workspace validation

The workspace adds detachable/dockable pages and inspectors, saved layouts, a timeline focus mode, a side-by-side layout, global search by default, format-specific column ordering, persistent resource preferences and shortcuts for rules and custom profiles.

Local Qt verification (Linux/offscreen, **not** Windows executable qualification):

- UI suite and related layout/timeline/release checks: **310 passed, 3 skipped**, 347.60 seconds.
- Subsequent focused column/layout checks: **25 passed**, 10.02 seconds.
- Covered: detach/reattach and restored layout; timeline-only and side-by-side views; global search of inactive artifacts and opening the matching source; applying and saving resource limits; immediate column-order persistence; reorder/hide from the column dialog; pinned-column order; restart from timeline focus; narrow-panel controls and chart-only display; creating a rule targeting one column; carrying column presentation across cases without carrying case filters.
- Ruff and `git diff --check` pass.
- Application captures use synthetic data: [analysis](../assets/fireblade-workspace-v022.png), [timeline](../assets/fireblade-timeline-v022.png).

The Windows workflow builds a fresh standalone executable and independently gates publication on focused source tests, native readers/storage, visual checks, 320 analyses and the 3-GiB workflow. Results are linked from the release when publication succeeds. The full Python 3.11–3.13 source matrix remains available on request.

Collection jobs remain sequential. Import/query thread settings apply to DuckDB work; external engines retain their own scheduling options. JSON profiles describe recognition, types, presentation and transforms; .NET readers use the existing plugin contract. Existing archives, exports and source-integrity checks are retained.
