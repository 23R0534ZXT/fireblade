# Données de démonstration

`demo.csv` contient des événements synthétiques pour explorer la grille, les filtres, groupes et couleurs. Ce fichier ne provient pas d’une enquête réelle et ne représente pas une charge de performance multi-Go.

Depuis le programme, utiliser Ouvrir un fichier et choisir ce CSV. Aucun exemple externe n’est requis au démarrage normal du `.exe`.
