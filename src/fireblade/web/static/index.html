Analyse a disk

The walk copies the artifacts it recognises out of the source, then the ordinary collection reads them. The case must live outside the analysed volume.

Importing

Starting…
Stopping an import keeps what was already written in the case: nothing is deleted, the half-read file stays visible in the collection report.

Import report

A file the collection could not read stays unread until somebody asks. The source is read, never modified, and the choice is written in the collection's report with the file's hash.
Set aside parks a file out of the counts without losing its entry. Remove deletes it from the evidence tree, and only when its hash is still the one collected.

Provenance and SHA-256

What this analysis came from, and the fingerprint the collection recorded when it read the source. Nothing is recomputed here: the report is the one the import wrote.

Profiles and compatibility

A presentation plugin declares columns and their types; the source values stay untouched. Profiles the core declares come first, then the plugins installed on this instance.
Timeline Explorer reader DLLs: not available in this edition — the image does not carry the .NET plugin host, and running a third-party DLL inside the service container is a decision to take, not an oversight.
